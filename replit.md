# Static Website

## Overview
This is a static HTML website built with Mobirise. It consists of multiple HTML pages with supporting assets (CSS, JavaScript, images).

## Project Structure
- `index.html` - Main homepage
- `contact-us.html` - Contact page
- `services.html` - Services page
- `privacy-policy.html` - Privacy policy page
- `assets/` - Static assets including:
  - CSS/JavaScript libraries (Bootstrap, embla, parallax, etc.)
  - Images
  - Fonts and icons

## Running Locally
The site is served using `npx serve` on port 5000.

## Deployment
This is a static website deployment that serves the HTML files directly.
